# Notes Activity Calendar

A sidebar calendar for browsing Markdown notes by creation and modification date, with optional Chinese lunar dates and daily note shortcuts. The current interface is in Chinese.

## Features

- A monthly activity calendar and a list of notes created or modified on the selected date.
- Optional heatmap, lunar dates, festivals and solar terms.
- Open or create daily notes using the core Daily notes configuration; optionally match names with a suffix in the same directory.
- Folder and tag filters, excluded folders, and a hover preview.
- Right-click a date to open its daily note, create a note named after the date, or copy the date.

## Installation

In Obsidian, enable community plugins, then search for **Notes Activity Calendar** and install and enable it. Open it with the calendar ribbon icon or the `打开日历` command. For manual installation, put `main.js`, `manifest.json` and `styles.css` in a folder named `notes-activity-calendar` inside your vault's configured plugins directory.

## Activity and privacy

The plugin indexes Markdown files in the vault. Creation dates use, in order, an enabled date in the filename, configured frontmatter fields, or the file creation time. When filename-date recognition is disabled, creating a note named for a past date records its actual creation date.

Modification history is recorded while Obsidian is running and the plugin is enabled. At first startup the plugin uses each file's current last-modified time as a baseline; it cannot reconstruct earlier edits. Edits made while the plugin is stopped can only be inferred from the last-modified time on restart. A note created and modified on the same creation date is listed once under created. Renames carry existing records to the new path. Deleted notes are hidden, but their paths are retained in history so restored files can reappear.

The plugin saves date, file path and last modification time in its plugin data file. It does not save note contents in the history or send data to a network service. Activity history is collected across the vault; filters and excluded folders affect display. Plugin data may be synchronized by your vault synchronization service; simultaneous offline edits on multiple devices can cause data-file conflicts and have not been validated.

## Requirements and development

Obsidian 1.14.5 or later. Desktop has been tested on macOS; mobile use has not yet been verified.

```sh
npm ci
npm run build
npm test
npx eslint src/main.js
```

`main.js` is generated by esbuild using pinned dependencies. `styles.css` and `manifest.json` are release assets. Tests use simulated notes and do not require a real vault.
