在 Obsidian 侧栏里查看一个月的笔记活动。点击日期，就能回到当天新建或修改的文档；也可以显示农历、节气，并快速打开当天日记。

> 顶部链接切换的是说明语言，不改变插件界面。插件目前使用中文界面。部分阅读页面会在浏览器或 GitHub 中打开另一份说明，而不是在原页面内切换。

![日历功能示意：左侧说明，右侧为整月活动热力图和选中日期的笔记列表](docs/images/overview-zh.png)

*图片为使用虚构笔记绘制的功能示意图，不是实际软件截图，也不包含用户资料库内容。*

## 它能帮你做什么？

| 你想做的事 | 使用方式 |
| --- | --- |
| 找回某天写过的内容 | 点击日期，分别查看当天新建和修改的笔记；点击标题打开。 |
| 回顾一个月的写作活动 | 打开热力图，颜色越深表示活动越多；悬停日期查看简短预览。 |
| 跳到其他月份 | 使用左右箭头，点击月份标题选月，或点击“今天”返回。 |
| 只看某个项目 | 启用文件夹、标签筛选，或从显示中排除指定文件夹。 |
| 写当天日记 | 沿用核心“日记”的文件夹、日期格式和模板，打开或创建该日的日记。 |
| 查看农历与节气 | 按需显示农历日期、节日和节气。 |

## 日期也是快捷入口

右键点击日期，可以打开或创建日记、在自选文件夹中新建普通笔记，或者复制日期。开启“宽松匹配日记”后，也能识别日期后带有标题的笔记，但匹配范围**仅限配置的日记目录**，不会串到其他年份或文件夹。

![日期菜单功能示意：新建日记、新建普通笔记、复制日期](docs/images/actions-zh.png)

*这是功能示意图，不是截图。只有点击“复制日期”后，插件才会把选中的日期写入剪贴板。*

## 安装与打开

1. 在 Obsidian 中打开“设置 → 第三方插件”，启用第三方插件。
2. 浏览并搜索 **Notes Activity Calendar**，安装后启用。
3. 点击侧栏功能区的日历图标打开。在插件设置中选择每周起始日、热力图、农历、筛选与悬停预览。

手动安装时，从已发布版本下载 `main.js`、`manifest.json`、`styles.css`，放入资料库已配置插件目录下的 `notes-activity-calendar` 文件夹，再启用插件。不要把源码压缩包当成可直接安装的发布包。

**需要 Obsidian 1.14.5 或更新版本。** 旧版曾在 macOS 上测试；本次改动已通过自动化测试，仍需要桌面端与移动端的实际人工验收。

## 日期和历史如何计算？

- 创建日期按顺序取值：已启用的文件名日期、配置的文档属性日期字段、文件创建时间。如果不希望标题中的过去日期覆盖实际创建日期，可关闭文件名日期识别。
- 修改历史仅在 Obsidian 运行且插件启用期间记录。首次运行以文件当前的最后修改时间为基线，无法还原更早的编辑；停用期间的变化只能通过重启时的最后修改时间推断。
- 同一天创建并修改的笔记只列在“新建”中。重命名会迁移已有历史；删除的笔记不显示，但历史保留路径，以便恢复文件后重新出现。
- 历史覆盖整个资料库。筛选和排除文件夹影响显示，不阻止历史收集。

## 隐私与使用边界

插件在自己的数据文件中保存日期、文件路径和修改时间，不在历史中保存笔记正文，也不把数据发送到网络服务。读取设置和历史时会校验数据，丢弃无效条目。资料库同步工具也可能同步插件数据；多设备同时离线编辑可能造成数据冲突，目前尚未验证。

全库活动统计需要枚举 Markdown 文件。复制日期只在用户操作后写入剪贴板，从不读取剪贴板。这些能力可能继续显示在自动审核的披露项中；进入插件目录或通过检查都不代表经过人工安全审核。

核心“日记”没有公开的设置读取接口，因此兼容访问包含运行时校验；接口不可用时使用默认值。无效路径会阻止创建日记，而不会让整个日历崩溃，也不会悄悄改到其他目录写入。

## 顶部徽章是什么？

它们是 [Shields.io 动态徽章](https://shields.io/)，不是 Obsidian 强制要求的固定模板。版本徽章随 GitHub 正式发布更新。下载徽章链接到 Obsidian 官方插件页：当前环境未能可靠验证数字徽章的返回值，因此这一版先链接到官方来源，没有拿 GitHub 附件下载量冒充插件下载量，也没有编造数字。详见[徽章来源与维护说明](docs/BADGES.md)。不同阅读页面可能缓存徽章，或在外部打开链接。

## 开发与验证

```sh
npm ci --ignore-scripts
npm run check
```

检查包括严格类型校验、零警告代码检查、生产构建和内存模拟回归测试。源码位于 `src/*.ts`，使用固定版本依赖生成 `main.js`。发布附件只包含 `main.js`、`manifest.json` 和 `styles.css`；许可证全文嵌入构建文件。创建或发布版本前请阅读[发布与安全检查说明](docs/RELEASING.md)。
